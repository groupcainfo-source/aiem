牙科旅游究竟涉及什么

出国看牙，是把一项医疗决定与一次旅行结合在一起。医疗部分完全由牙医负责。我们负责的是围绕它的一切：寻找可以核查的诊所、取得书面报价、安排交通和住宿、在就诊时提供翻译，并保持诊所与您之间的协调。安排得当的行程，能让您专注于治疗本身，而不必操心各种琐事。

流程如何运作

  1. 您向我们简要描述自己的情况，如有 X 光片或既往治疗记录，请一并提供。
  2. 我们请合作诊所审阅这些资料，并提出治疗方案和书面报价。
  3. 您比较各家报价：包含哪些项目、需要几次就诊、诊所提供什么保证，以及可能产生哪些额外费用。
  4. 您选定之后，我们规划行程：机票、酒店、机场接送和就诊安排。
  5. 在阿尔巴尼亚期间，如果您需要，我们可以陪同并在就诊时翻译。
  6. 治疗结束后，我们保持联系，并协助您就复诊问题联系诊所。

不懂牙科也能比较诊所的方法

单靠宣传册您无法判断诊所的临床水平，但有些事情可以查验，它们能说明一家诊所是如何运作的：

  • 牙医和诊所是否持有执照，以及他们是否愿意告诉您由谁来为您治疗。
  • 报价是否是书面且逐项列明的，并写明哪些不包含在内。
  • 是否先做影像检查和诊断再提出方案，而不是电话里直接报价。
  • 使用哪些材料和品牌，以及您能否拿到书面说明。
  • 质保涵盖什么、期限多久，以及为保持质保有效您必须做什么。
  • 诊所如何处理并发症，以及您回国之后是否还能联系到诊所。

切合实际地规划行程

有些治疗一次就诊就能完成，有些则需要多次就诊，中间还要留出愈合时间。例如涉及种植牙时，各阶段之间要等多久由牙医决定，很多情况下间隔以月计算，这可能意味着要来两趟。请在一开始就要求诊所给出切合实际的时间表，并且多订几天，不要为了赶航班而缩短治疗。

决定之前应当问的问题

  • 治疗的每个阶段由谁来做，是否始终由同一位牙医负责？
  • 有没有更便宜或创伤更小的替代方案，为什么推荐这一种？
  • 有哪些风险，如果结果不如预期会怎样？
  • 需要就诊几次，每次多长时间？
  • 质保不包括哪些情形？
  • 我回国之后联系谁，多快能得到回复？

哪些人会使用这项服务

我们的客户多数是居住在国外、希望在阿尔巴尼亚接受治疗的人，其中包括把治疗与回乡探亲结合起来的阿尔巴尼亚侨民。我们也为需要可靠本地协调人的救援公司和旅行组织者提供帮助。如果您的行程包含在阿尔巴尼亚更长时间的停留，我们的团队还可以支持相关需求，例如看房与房产投资。

术后护理与随访

好的治疗也包括您离开诊椅之后的事情。出发前，请确保您清楚术后护理要求、哪些症状需要联系诊所，以及对方多快会回复。请保留治疗记录、X 光片和所用材料的副本，以便您所在地的任何牙医都能继续为您治疗。希望接待国际患者的诊所、酒店和救援公司，可以申请加入我们的专业人脉网络。

  • 要求提供您所用语言的书面术后护理说明。
  • 约定一旦感觉不对，联系谁、通过什么渠道。
  • 回国之后，安排到您自己的牙医处复查。

启动项目前我们需要您提供什么

  • 您所在的国家、希望出行的日期以及能停留的时间。
  • 您考虑的治疗项目，或希望解决的问题。
  • 您已有的任何 X 光片、扫描片或治疗记录。
  • 您是独自出行还是有同伴。
  • 您用于沟通的语言。

我们不是牙科诊所，也不提供医疗建议。诊断、治疗方案和价格均由牙医决定。任何治疗，也请同时咨询您自己的牙医或医生。

服务流程

  1. 描述您的需求选择支持类型，告诉我们您需要什么。需求越具体，首次答复就越有针对性。
  2. 专业人员回复您的需求会送达该服务对应的专门团队，专业人员通常会在几分钟内回复。
  3. 审阅书面方案范围、时间和价格均以书面形式列明，不设任何义务，也不施加压力。
  4. 执行与交付由一位明确的负责人统筹工作，并交付可直接使用的文件。

常见问题

你们是牙科诊所吗？

不是。我们协调整个流程，并为您对接合作诊所。治疗仅由诊所的医生实施。

我如何知道治疗费用？

诊所在评估后给出价格。我们会将其整理为书面报价，并列明任何额外费用。

回国后需要复查怎么办？

治疗前，我们会向诊所询问保修和后续复查的安排，您可在报价中看到这些内容。

在国外做牙科治疗安全吗？

安全与否取决于诊所和牙医，而不是国家。因此我们会在您出发之前，协助您核查执照、书面报价、材料、质保和随访安排。

我应该计划停留几天？

这取决于治疗内容。诊所应当给出切合实际的时间表，我们也建议多留几天余量，避免行程过于仓促。

你们能安排酒店和交通吗？

可以。我们安排酒店、机场接送和当地交通，也可以陪同您并在就诊时翻译。

回国之后如果出现问题怎么办？

在您做决定之前，我们会向诊所询问质保和随访安排，让您心中有数；如果有需要，我们也会协助您联系诊所。
